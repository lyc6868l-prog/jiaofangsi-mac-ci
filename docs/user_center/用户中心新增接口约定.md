# 用户中心新增接口约定

> 对应桌面端 v2.0 用户中心改版  
> 现有用户资料、微信绑定、SSO、VIP 接口保持不变，本文只列出这次 UI 落地新增的接口。

---

## 1. 头像上传

桌面端入口：用户中心头像点击。

```text
POST https://auth.jiaofangsi.top/wechat-auth/v1/account/avatar
Authorization: Bearer <unified_access_token>
Content-Type: multipart/form-data
```

表单字段：

```text
file: 图片文件
```

限制建议：

```text
格式：jpg / jpeg / png / webp
大小：<= 5MB
尺寸：建议 <= 2048 x 2048
```

响应：

```json
{
  "success": true,
  "avatar_url": "https://cdn.example.com/avatar/xxx.png"
}
```

桌面端已实现：

```text
选择本地图片
→ 本地预览
→ 若 authMode == unified，调用 uploadAvatar
→ 后端返回 avatar_url 后刷新资料
```

旧版邮箱账号暂不调用上传接口，提示“绑定微信后支持上传”。

## 4. 创建打赏订单

```text
POST https://auth.jiaofangsi.top/wechat-auth/v1/tip/orders
Authorization: Bearer <access_token>
Content-Type: application/json
```

请求：

```json
{
  "tier_id": "benz_shard",
  "quantity": 1,
  "wish": "拿去买烟，下版安排更顺手的快捷键！",
  "pay_channel": "wechat"
}
```

响应：

```json
{
  "order_id": "TIP202611210001",
  "amount": 100,
  "status": "pending",
  "payment_url": "https://pay.example.com/...",
  "qr_code_url": "https://pay.example.com/qr/....png",
  "certificate_id": "CERT202611210001"
}
```

### 重要安全约束

- 金额由服务端根据 `tier_id × quantity` 计算，**不能信任客户端金额**
- 必须校验 tier 是否有效、是否上架
- 订单必须幂等
- 支付回调必须验签
- 只有支付成功后才能发放封号、芳名录展示和荣誉状
- 封号/荣誉必须写入数据库，不能只存在客户端

### 支付状态

建议状态：

```text
pending
paid
failed
cancelled
refunded
```

桌面端在收到 `payment_url` 后会打开支付页面。  
真正的“打赏成功、封号、荣誉状”应以后端支付回调为准。

## 5. 封号 / 荣誉展示

当前桌面端已预留用户中心封号徽章位置：

```text
用户中心头像下方
★ 封号名称
```

建议在资料接口中增加可选字段：

```text
GET /v1/account/profile
```

响应增加：

```json
{
  "account_id": "...",
  "stage_name": "...",
  "avatar_url": "...",
  "honor_title": "造车联合创始人"
}
```

桌面端可以在下次 `refreshAccountSnapshot()` 时读取并展示。  
当前代码中的封号徽章是本地预留状态，还没有绑定真实资料字段。
