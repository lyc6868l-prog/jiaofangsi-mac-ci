# 教坊司DJ便捷工具项目总说明

## 项目定位

教坊司DJ便捷工具是面向 DJ 音频整理与批量处理场景的桌面工具项目，首版聚焦音频处理主链路，不在主线稳定前扩张范围。

## 首版目标

- 建立 `Flutter Desktop + Python Runtime + Rust Worker` 三层架构
- 优先打通 `cleanup_dup` 模块完整闭环
- 冻结协议、日志、错误码、安全与测试素材规范
- 建立可回滚、可定位、可归档的开发与修复体系

## 首版固定模块

1. 解锁
2. 转码
3. 清理 / 查重
4. 封面 / 补字
5. 首拼生成
6. U 盘备份

## 当前阶段定位

当前仓库处于阶段 0 与阶段 1 的启动建设阶段，优先完成目录骨架、治理文档、测试素材目录和协议基础说明。

## 当前完成标准

- 目录骨架齐全
- 基础治理文档可查
- 文件对照表持续同步
- 后续可直接进入三层骨架搭建
