# 安全规范

## 本地桥接安全

- 本地桥接仅允许绑定 `127.0.0.1`
- 默认端口必须可配置
- 生产包禁止监听外网地址

## 凭证安全

- 密码不得落盘
- token 必须进入安全存储方案
- 日志中不得明文记录 token、密码、验证码

## 文件操作安全

- 删除、覆盖、批量改名必须有确认层
- 默认禁止对系统敏感路径执行批量操作
- 输出目录与输入目录冲突时必须明确提示

## 外部命令安全

- 所有参数必须显式传参
- 不拼接危险 shell 字符串
- 路径与用户输入必须先校验后执行

## 执行要求

- 安全规则视为首版基础能力，不得后补
- 安全规则变更必须同步更新治理文档与记录文件
