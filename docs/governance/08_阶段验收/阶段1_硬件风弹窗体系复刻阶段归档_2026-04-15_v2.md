## 五、技术说明

### 黄线问题根因
在 `hardware_ui.dart` 的 `_HardwareDialogHeader` 中存在：
```dart
border: Border(
  bottom: BorderSide(color: Colors.white.withValues(alpha: 0.05)),
),
```
该 5% 透明度的白色边框在某些显示条件下呈现黄色视觉效果，已移除。

### Python Runtime 问题说明
- App 内置的 `runtime/python/` 和 `runtime/dj_runtime_py/.venv/` 配置不完整
- Python 启动时未正确使用 venv 的 site-packages
- 开发模式下会 fallback 到 workspace .venv 可正常工作
- 正式打包前需修复 `bundle_runtime_assets.sh`
