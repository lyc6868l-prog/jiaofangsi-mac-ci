## 本阶段目标

为主壳顶栏添加自动更新功能，实现"检查更新 → 下载 → 重启以更新"的完整闭环，并定义与服务器端的更新检查接口协议。

### 3. 更新按钮交互设计

| 状态 | 按钮外观 | 用户操作 |
|------|---------|---------|
| 无更新 | 完全隐藏 | — |
| 发现新版本 | 红色闪动圆形按钮 + 下载图标 | 悬停提示"发现新版本 Vx.x.x，点击下载"，点击开始下载 |
| 下载中 | 红色圆形进度条 | 悬停提示"正在下载更新..." |
| 下载完成 | 红色闪动圆形按钮 + 下载图标 | 悬停提示"点击重启以更新"，点击执行替换并重启 |
| 检查/下载出错 | 隐藏 | — |

### 4. 服务器接口协议

- 接口：`GET https://www.jiaofangsi.top/api/update/check?platform=macos&version=V1.9.0`
- 响应：`{ "has_update": bool, "version": string, "download_url": string, "release_notes": string, "file_size": int }`
- 安装包格式：ZIP，解压后为 `dj_flutter.app`

## 风险与遗留问题

1. **服务器接口未部署**：当前 `https://www.jiaofangsi.top/api/update/check` 不存在，按钮始终隐藏。后端部署后即可工作。
2. **安装包替换逻辑**：`installAndRestart()` 使用 `mv` + `unzip` + `rm` 命令，如果中途中断可能导致应用损坏。建议后续增加回滚机制。
3. **下载中断恢复**：当前不支持断点续传，大文件下载中断需重新下载。
4. **签名校验**：当前未对下载的 ZIP 包做签名/哈希校验，存在中间人攻击风险。建议后续增加 SHA256 校验。

## 下一步动作
