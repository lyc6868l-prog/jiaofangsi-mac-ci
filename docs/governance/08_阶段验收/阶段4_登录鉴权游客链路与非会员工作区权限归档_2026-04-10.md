# 阶段4 登录鉴权游客链路与非会员工作区权限归档

## 归档信息

- 归档时间：2026-04-10
- 归档范围：`apps/dj_flutter`、`runtime/dj_runtime_py`、`docs/governance` 中与真实登录、游客体验、用户中心、会员识别、登录页窗口控制、非会员工作区权限策略直接相关的实现与治理文件
- 当前状态：已完成真实登录与游客体验主链路接通，已形成可恢复、可验证、可继续联调的阶段性交接快照
- 对应阶段：阶段4 登录 / 用户中心 / 服务器对接

## 本阶段目标

- 将桌面端启动链路固定为先进入登录页，禁止自动跳过登录直接进入主壳。
- 将账号密码登录切换为真实认证服务器 `https://auth.jiaofangsi.top`，并按线上真实字段与返回结构完成适配。
- 打通游客体验注册、剩余时间恢复、到期处理、主壳可用范围与登录页提示行为。
- 完成用户中心、登出、登录页底部链接、窗口控制按钮等真实可用交互。
- 收敛非会员账号进入各模块后的权限表现：页面完整可见、非开始按钮灰化不可用、开始按钮点击后弹出会员提示。

## 当前状态结论

- 应用启动已固定进入登录页，只有服务端验证成功后才会切换到主壳。
- Flutter 与 Python runtime 已完成真实认证服务器对接，登录、权益查询、资料查询、游客注册、游客状态检查均按线上真实结构解析。
- 游客体验链路已形成闭环：首次分配凭证、重开恢复倒计时、到期隐藏入口、到期后“去开通”闪烁、成功账号登录后停止闪烁。
- 游客体验用户可进入主壳并使用限定工作区，且主壳中不显示用户中心入口。
- 非会员正式账号可切换各模块导航，模块页面完整显示，但除底部开始按钮外的控件均灰化不可操作；点击开始按钮后弹出会员提示弹窗。
- 主壳顶部功能卡状态灯已收敛为三态：绿色“运行中”、橙黄色“待机”、红色“请开通会员后使用”。
- 当前结论为：阶段4 的真实登录、游客体验、基础权限分流与桌面端交互链路已进入“可交接继续联调 + 可继续做视觉修边”的状态。

## 已完成内容

### 一、真实认证服务器接入已完成

- 认证服务器基地址已固定为 `https://auth.jiaofangsi.top`。
- 用户登录已改为 `POST /auth/login`，请求字段使用 `login_name` + `password`。
- 游客接口已改为：
  - `POST /api/guest/register`
  - `POST /api/guest/check`
- 游客请求字段统一改为 `machine_hash`。
- 权益判断已适配真实返回结构，会员识别支持 `vip`、`dj_tool`、`web_vip` 任一有效即视为会员。
- 软件会员到期时间优先从 `dj_tool`，再回退 `vip`、`web_vip` 解析。

### 二、登录与会话链路已完成收敛

- 启动时不再依据本地快照自动跳入主壳。
- 登录成功后才会切换主壳窗口尺寸并进入主壳。
- 登录页尺寸固定为 `420x650`，主壳窗口尺寸固定为 `1440x968`。
- 登出时已修复“先缩窗再跳页”导致的主壳阻塞与卡顿问题，改为先路由回登录页，再由登录页负责窗口切换。
- Python runtime 中曾导致 35 秒超时的安全存储问题已修复，登录链路恢复正常。

### 三、游客体验闭环已完成

- 首次打开登录页可点击“免费体验”。
- 点击后显示“正在分配试用凭证...”，成功后进入主壳。
- 再次打开应用时，登录页可恢复显示“体验剩余 HH:MM:SS”。
- 游客试用有效期内可再次点击按钮进入主壳。
- 试用到期后游客按钮消失，“去开通”按钮进入红光微闪状态。
- 用户只要成功使用账号密码登录过一次，过期后的“去开通”按钮就不再闪烁。
- 游客态进入主壳时不显示用户中心入口。

### 四、登录页与用户中心真实交互已完成

- 登录页底部“去注册 / 去开通 / 忘记密码”已接入真实浏览器跳转。
- 登录页错误提示区已保留固定占位，避免报错时整体布局突然下移。
- 登录页标题图片区域已按用户反馈多轮调整，并支持向上搜索仓库根 `图片/` 目录加载资源。
- 登录页右上角最小化 / 关闭按钮已接入真实窗口控制，且补充了热区、悬停、按压反馈与语义标识。
- 用户中心已移除硬编码邮箱 fallback；未登录账号不再显示默认邮箱。

### 五、非会员账号工作区权限表现已按最新规则收敛

- 非会员正式账号登录后，不再锁导航区。
- 各功能模块页面仍可正常切换与完整显示。
- 除底部开始按钮外，其余输入、拖拽、配置、切换类控件统一灰化并禁用交互。
- 开始按钮保留可点击能力，点击后弹出“请开通会员后使用，免费体验期间也可使用。”提示弹窗。
- 已开通会员与游客体验用户仍保持真实功能可用，不走上述锁定提示。
- 功能卡状态灯已改为：
  - 绿色：运行中
  - 橙黄色：待机
  - 红色：请开通会员后使用
